# Care-BuildPro

Care-BuildPro simplifies construction management with project tracking, budget control, expense management, labour attendance, and payroll.

Manage your construction records efficiently with secure local data storage, all in one easy-to-use app.

## Features
- Project Tracking
- Budget Control
- Expense Management
- Labour Attendance
- Payroll Management
- Secure Local Data Storage (SQLite)

## Tech Stack
- Flutter / Dart
- SQLite
